⚙ Тохиргоо ба заавар

1. GitHub Pages

  1. Энэ файлыг index.html нэрээр GitHub repo-доо upload хийнэ.
  2. Settings → Pages → Deploy from a branch → main / (root).

2. AI холбох (Cloudflare Worker)

  1. dash.cloudflare.com → Workers & Pages → Create → Hello World.
  2. Доорх кодыг хуулж Worker-ийн editor-т буулгаад Deploy дарна. (ALLOWED_ORIGIN таны GitHub Pages домэйнээр аль хэдийн тохируулагдсан.)
  3. Settings → Variables and Secrets → ANTHROPIC_API_KEY (Secret) нэмнэ.
  4. Worker-ийн URL-ийг доор оруулж хадгална.
